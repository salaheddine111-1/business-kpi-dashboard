# 📊 Interactive Business KPI Dashboard (Streamlit)

## 🎯 Overview
This project implements a fully interactive web-based dashboard using **Streamlit** and **Python** to visualize business key performance indicators (KPIs) and transactional trends in real time.

## 🛠️ Tech Stack
* **Python** for backend logic and data processing.
* **Pandas** for structured data manipulation.
* **Streamlit** for rapid UI design and web deployment.

## ✨ Key Features
* **Interactive Metrics Cards:** Instantly view Total Revenue, Average Order Value (AOV), and Total Transactions.
* **Dynamic Data Viewer:** Filter and inspect raw transaction records directly from the web interface.
* **Visual Analytics:** Built-in bar charts tracking revenue performance across different product categories.
